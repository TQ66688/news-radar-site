# 新闻雷达 · 产品页

**新闻雷达**的产品介绍页源码。本站就是这个仓库本身，无构建步骤。

> 应用本体是一个**本地运行**的工具（FastAPI + WebSocket），跑在 `127.0.0.1:8850`，
> 没有云端、没有账号，API Key 也只留在本机。所以这里的页面只做介绍，
> 网页上点不进去 —— 应用不在公网。

## 这个页面是什么

一个单页的产品介绍站，用来说明新闻雷达是干什么的：

- **四大视图** —— 看板（六大国内热榜）/ 信息流（国内外资讯按天分组）/ 财经专线 /
  搜索（含 AI 找）
- **筛选** —— 时间四档（全部 / 今天 / 近 3 天 / 近 7 天）+ 按来源筛选
- **五个 AI 能力** —— 今日简报、词条解读、AI 找新闻、自动翻译、导出简报
- **多选导出** —— 勾选后导出 Word / Markdown，可选附一段 AI 简报

## 技术

原生 HTML + CSS，**零依赖、零构建、零 CDN**：

```
index.html          单页
css/site.css        全部样式（设计令牌用 --vx-* 前缀）
fonts/              6 个 woff2（Anton / Space Grotesk / Space Mono 的 latin 子集）
img/                9 张应用实拍截图
favicon.svg
```

资源全部用相对路径，`git clone` 后**双击 `index.html` 就能看**，不需要起服务器。
字体缺失时会静默落到系统字体栈，页面不会破相。

### 设计

遵循 **The Verge** 的设计系统（近黑画布 `#131313`、酸性薄荷 `#3cffd0` + 紫外 `#5200ff`
做危险色强调、巨号展示标题、圆角色块卡片、StoryStream 竖线时间线）。
规格参考 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
的 `theverge/DESIGN.md`。

两条硬规矩：**零渐变、零投影** —— 层级全靠 1px 发丝边框和饱和色块；
展示字体只用于 ≥60px 的标题，绝不下放到 UI。

中文排版做了适配：展示字体没有中文字形，中文走系统黑体栈；中文标签的字距用
0.05–0.08em，不照抄拉丁那套 1.5–1.9px（会把汉字拉开）。

## 部署

托管在 Cloudflare Pages，连本仓库自动构建。构建命令留空，输出目录为 `/`。
